Роутинг между микрофронтендами

Один адрес, одна история, один писатель. Префикс принадлежит Shell, хвост — МФ.

Контракт (props / аргументы mount)

<Catalog basename="/catalog" path={path} navigate={navigate} />   // компонент
mount(el, { navigate })                                            // любой фреймворк

// Shell
const navigate = (to) => { history.pushState(null, '', to); setPath(to) }
addEventListener('popstate', () => setPath(location.pathname))     // «Назад» / «Вперёд»

// страховка (Navigation API, Baseline 2026): ловит и push, и replace, и traverse
navigation?.addEventListener('currententrychange', () => setPath(location.pathname))

Факты

  • pushState() / replaceState() не вызывают popstate. Он срабатывает только на действия браузера: «Назад», «Вперёд», history.back().
  • Navigation API: событие navigate до перехода (на первой загрузке не срабатывает), currententrychange после. В Chrome оба срабатывают и на pushState.
  • Маршруты, на которые ссылаются другие команды, — контракт. Его покрывают тестами и меняют через переходный период с редиректами.
